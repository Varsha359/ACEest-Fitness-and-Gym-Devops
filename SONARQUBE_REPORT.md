## Running SonarQube Analysis

### One-time Setup
```bash
# Start SonarQube server
docker run -d -p 9000:9000 --name sonarqube sonarqube:lts-community

# Install sonar-scanner
npm install -g sonarqube-scanner
```

### Run Analysis
```bash
# Generate a token in SonarQube web UI (Admin > Security > Tokens)
# Or programmatically:
TOKEN=$(curl -s -u admin:admin -X POST \
  "http://localhost:9000/api/user_tokens/generate?name=aceest-scanner" | \
  python3 -c "import sys,json; print(json.load(sys.stdin)['token'])")

# Run scanner
sonar-scanner \
  -Dsonar.projectBaseDir=. \
  -Dsonar.sources=app \
  -Dsonar.tests=tests \
  -Dsonar.host.url=http://localhost:9000 \
  -Dsonar.token=$TOKEN \
  -Dsonar.projectKey=ACEest-Fitness \
  -Dsonar.projectName="ACEest Fitness and Gym"
```

### View Results
Open: http://localhost:9000/dashboard?id=ACEest-Fitness

## Integration with Jenkins

To enable in Jenkins:
1. Install SonarQube Scanner plugin in Jenkins
2. Configure SonarQube server: Jenkins > Manage Jenkins > Configure System > SonarQube servers
3. Name it `SonarQube` (matches the Jenkinsfile)
4. Set host URL: `http://sonarqube-server:9000`
5. Provide authentication token
6. Run the Jenkins pipeline
